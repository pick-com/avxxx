# 设计稿 × PRD × 技术方案对齐表

日期：2026-10-15
范围：设计稿「视频网站设计」全部 70 个画板（67 个页面 + 3 个组件）、`docs/PRD.md`（rev 25）、`docs/PRODUCT_REVIEW_AND_TECH_PLAN.md`

70 个画板全部有 PRD 章节对应，全部已落到技术方案。逐项对齐后发现 3 类问题：**定位冲突 1 项**（需决策）、**PRD 与设计稿不一致 9 项**、**技术方案原先缺失或与 PRD 数值不符 21 项**（本次已补进技术方案第 3.13–3.14 节）。

阶段按 PRD 第 21 节的里程碑：Alpha（内测）→ Beta（公测）→ V1（正式上线）→ V1.1；「后续」= PRD 未排期。

## 1 需要决策的定位冲突

PRD 把 REEL 定位为面向大众的视频站：第 15 节「不面向 13 岁以下」，设有青少年模式，广告屏蔽成人内容品类（`AdminAds`）。仓库现有数据是 JAV 目录（`performers` 为女演员、`releases` 为品番作品），播放来源是第三方成人站点。

两者不能同时成立：

| 选项 | 含义 | 影响 |
|---|---|---|
| 大众视频站（按 PRD） | 片库来自授权的影视内容；现有 JAV 采集与 `internal/media` 不进入 REEL | 技术方案按本表执行；采集框架（来源、任务、去重、审核）可复用，数据不复用 |
| 成人站（按仓库数据） | 片库沿用 JAV 目录 | PRD 第 15、16、19 节和 `AgeGate` 需重写：进站 18+ 验证、去掉青少年模式、成人广告网络；技术方案第 2.2 节的合规要求生效 |

技术方案第 2.2 节的合规评审是按成人站写的；本表按 PRD 的大众视频站对齐。选成人站时，`AgeGate`、青少年模式、广告品类三处要按技术方案第 2.2 节改。
