## 1. 概述

REEL 是一个以「视频」和「演员」为双核心的视频网站：用户既能像 YouTube 一样看视频，也能顺着演员找作品；手机端是主要场景，支持多语种和浅色 / 深色外观。

- **设计稿**：[视频网站设计（Design 画布）](https://claude.ai/artifact/RGKRixRrf5PqYiZDorq3jG)。本文每个功能都标注对应画板文件名（如 `Video.dc.html`），PRD 与画布以画板为唯一对齐单位。
- **一句话定位**：看视频时随时认识演员，认识演员后一路看下去。
- **本期范围（V1）**：发现与搜索、播放（含多片源）、演员、用户基础功能、通知、多语种、外观主题、手机端、后台管理与数据质量。
- **不在本期**：会员付费、离线下载、用户上传、直播、多人档案（一个账号多个观看档案）。广告和弹幕已纳入本期，见第 16 节和 5.5 节。

### 目标与成功指标（上线后 90 天，建议值，待确认）

## 2. 目标用户与核心场景

五类用户，手机端为主；每类用户对应一条最短路径，设计稿按这些路径验收。

| 用户 | 典型场景 | 最短路径（画板） |
| --- | --- | --- |
| 追剧用户 | 下班路上用手机接着看昨晚的剧 | 手机首页「继续观看」→ 播放页 → 迷你播放器（`MobileHome` → `MobileVideo`） |
| 演员粉丝 | 看到某个演员，想知道 TA 还演过什么、当时多大 | 播放页主演 → 半屏详情 → 演员页作品（`MobileVideo` → `MobileActorSheet` → `MobileActor`） |
| 随便看看 | 没目标，想找点好看的 | 发现页热门 / 分类 → 视频（`MobileDiscover` → `MobileVideo`） |
| 外语用户 | 用英文 / 日文 / 越南语界面，看带字幕或配音的视频 | 语言切换 → 播放页字幕与音轨（`I18n` → `MobileSources`） |
| 运营与编辑 | 处理入库失败、重复、缺失信息和举报 | 后台总览待处理 → 对应工作台（`AdminDashboard` → `AdminPipeline` / `AdminDedupe` / `AdminAudit`） |

## 4. 发现

发现的目标是让用户 3 次点击内开始播放：首页给个性化内容，热门 / 新上线 / 分类给浏览路径，搜索兜底。

### 4.1 首页 · `NavHome` / `MobileHome`

- 主推横幅（运营排期，空位由推荐补）→ 分类 chips → 继续观看 → 为你推荐 → 你关注的演员有新作 → 热门演员。
- 未登录：去掉「继续观看」和「关注的演员」两行，顶栏头像换成「登录」按钮（`TopBar` 的 `loggedIn` 开关）。
- 手机端：迷你播放器常驻底部 Tab 上方，从播放页返回时不中断播放。

### 4.2 热门 · `NavTrending`

- 今日 / 本周 / 本月 / 年度四个榜，每小时更新；排序综合播放量、完播率、增长速度。
- 显示排名升降（▲ ▼ 新上榜），右侧放演员热度榜和热搜词。

### 4.3 新上线 · `NavNew`

- 「即将上线」可预约，上线当天发通知；下面按日期分组。
- 「只看关注的演员」开关。

### 4.4 分类 · `NavCategories`

- 类型方块 + 时长 / 年代 / 语言三组筛选 + 标签云；点击进入搜索结果页并带上筛选条件。

### 4.5 搜索 · `Browse` / `MobileSearch` / `MobileSearchTyping`

1. 输入中：联想词分类型显示（视频、演员、标签、最近搜索），未输入时显示最近搜索和热搜。
2. 结果页：顶部是匹配到的演员卡，下面是视频；筛选含类型、时长、上传时间、演员、清晰度、字幕语言、原声语言。
3. 召回：标题 / 简介 / 演员名（含别名、多语言名）/ 标签全文检索 + 多语言向量检索，搜「Night Flight」能找到《夜航的人》。
4. 无结果：按原词搜不到时，去掉常见修饰词（全集、第 N 集、在线看、高清、演员表等）再搜一次；仍无结果显示 `States` 01 空状态，并把搜索词记入后台无结果队列（`AdminSearch`）。

## 5. 播放

播放页的顺序按「先看、再认识、再继续看」排：播放器 → 标题与操作 → 章节截屏 → 片源 → 信息 → 主演 → 评论；右侧（手机为下方）是接下来播放。

### 5.1 播放器 · `Video` / `MobileVideo` / `MobilePlayerFull`

- HLS / DASH 自适应码率；清晰度、倍速、字幕、音轨、画中画、影院模式、全屏。
- 进度条悬停显示雪碧图预览帧和章节名；章节在进度条上分段。
- 键盘：空格播放暂停，← → 跳 5 秒，J / L 跳 10 秒，F 全屏，M 静音，C 字幕。
- 手机横屏手势：左侧上下滑亮度、右侧上下滑音量、双击左右 ±10 秒、长按临时 2×、左右滑拖进度；有锁屏按钮。
- 播放器在浅色主题下也保持黑底。

### 5.2 多片源 · `Video` 片源行 / `MobileSources` / `AdminVideo` 片源标签

一个视频（作品）可以有多个片源，按版本分四类：

| 版本 | 例子 | 与正片共享播放进度 |
| --- | --- | --- |
| 正片 | 1080p HDR 主片源 | — |
| 高画质 | 4K 片源 | 是 |
| 配音 | 英语配音 | 是 |
| 其他版本 | 导演剪辑版（时长不同） | 否，从头播放 |

- 规则：时长相差超过 2% 的片源归为「其他版本」。
- 默认片源按后台优先级；当前片源连续失败自动切换到下一个，并提示「已自动切到片源 B」（`States` 04）。
- 桌面端片源收成一行，点开才展开四个选项；手机端在设置面板的「片源」标签里切换。

### 5.3 章节与截屏

- 转码时自动截 24 张，后台挑 6 张作为章节截屏；放在标题和操作按钮下面，点击跳到对应时间，当前章节高亮。

### 5.4 互动

- 赞与踩分开两个按钮；收藏、稍后观看、分享；评论按最热 / 最新排序。
- 自动连播是真正的开关，默认开；同系列优先接下一集。

### 5.5 弹幕 · `DanmakuPlayer` / `MobileDanmaku`

- 未登录只能看，登录后才能发；新账号每分钟最多 3 条；单条最多 50 字。
- 广告期间弹幕隐藏，也不能发。
- 设置项：透明度、字号、速度、显示区域（1/4、半屏、满屏）、屏蔽类型（顶部、底部、彩色、重复、剧透）、语言过滤与自动翻译、防挡字幕、屏蔽词。
- 审核在 `AdminOps` 的「弹幕审核」标签，处理方式：折叠为剧透、删除并禁言、删除、放行。

#### 5.5.1 高能波峰（进度条上方的弹幕密度曲线）

波峰告诉用户「大家在哪里最激动」，可以直接点曲线跳过去。它是一条 16px 高的面积曲线，叠在进度条正上方，手机横屏同样显示。

**计数口径**

| 项 | 规则 |
| --- | --- |
| 时间轴 | 按作品时间轴记录，正片、高画质、配音共用一条；「其他版本」（时长差超过 2%）单独计算 |
| 分桶 | 每个视频固定 200 个桶，桶宽 = 时长 ÷ 200（最短 1 秒），曲线大小与视频长度无关 |
| 计哪些弹幕 | 只计审核通过且未被折叠、删除的弹幕；被举报处理后从计数里扣掉 |
| 防刷 | 同一用户在同一个桶里只算 1 条；内容重复的弹幕（相同或高度相似）在同一桶里只算 1 条；被禁言账号的历史弹幕不计 |
| 补充信号 | 可选：把「拖回来重看」的次数按 30% 权重加进去，弹幕少的视频也能有波峰 |

**计算与下发**

1. 发送弹幕时，在计数服务里给对应桶加 1（按视频 + 版本 + 桶号累加）。
2. 定时任务重算曲线：新上线 7 天内的视频每 1 分钟一次，其余每 10 分钟一次，只算有新弹幕的视频。
3. 重算步骤：去重计数 → 相邻 3 个桶滑动平均（去毛刺）→ 除以本视频最高桶，归一化为 0–255 的整数。
4. 结果是 200 个整数（约 1 KB），存成静态文件走 CDN，随播放配置一起返回，不单独请求。
5. 有效弹幕少于 50 条时不返回曲线，播放器不显示波峰（避免一两条弹幕画出假高峰）。

**前端显示**

- 用 SVG 面积路径绘制，颜色为强调色 35% 透明度；已播放部分比未播放部分略亮。
- 鼠标悬停或手指拖动进度条时，提示框显示该时刻的截屏缩略图和「此处 N 条弹幕」。
- 点击曲线等同点击进度条，跳到该时刻。
- 弹幕关闭时曲线一起隐藏；设置里另有「显示高能波峰」开关，默认开。担心剧透的用户可以单独关掉。
- 波峰最高的 3 处在曲线上方加小标记，供「跳到高能」使用；首次观看且开了「屏蔽剧透」时不加标记。

**与其他模块的关系**

- 广告：中插点避开波峰最高 3 处前后各 60 秒（`AdDepth` 的中插规则）。
- 章节：章节分界在波峰附近时，章节缩略图优先取波峰时刻的画面。
- 后台：`AdminOps` 弹幕审核按波峰排序，先审高峰时段的弹幕。
- 埋点：记录曲线点击次数、跳转后是否看满 30 秒，用来判断波峰是否真有用。

## 6. 演员

演员是和视频并列的核心实体：每个视频都能一步到达演员，每个演员页都能一步回到视频。

### 6.1 演员详情 · `Actor` / `MobileActor`

- 主照片、多语言名字与别名、作品数 / 总播放 / 粉丝 / 热度、生日 / 身高 / 国籍 / 出道 / 经纪、标签、简介、照片集。
- 出演作品：最新 / 最热 / 主演 / 客串 / 出演年龄筛选；每部作品标「2025 年拍摄 · 时年 28 岁」。
- 相似演员：匹配度用百分比（「92% 相似」），附一句理由（共演 6 部、观众高度重合…）。

### 6.2 演员库 · `NavActors`

- 「为你推荐的演员」用大照片卡，显示匹配度和推荐理由；下面是拼音首字母索引 + 筛选 + 演员网格。

### 6.3 悬停卡与半屏详情

- 桌面：鼠标停在演员头像上约 300ms 弹出资料卡（照片、资料、代表作、关注 / 查看主页 / 播放代表作）；弹出方向随卡片位置左右切换。键盘聚焦同样触发。
- 手机：没有悬停，点击演员弹出半屏详情（`MobileActorSheet`），视频在上方继续播放；上滑接近全屏看更多，点「完整主页」才跳转。

### 6.4 出演时年龄

1. 计算：视频「拍摄年份」− 演员生日年份。
2. 只有发布日期、没有拍摄年份时，显示「约 31 岁」。
3. 演员生日未填或不公开时，整行不显示。
4. 后台质量检查把缺拍摄年份、缺生日列入待补（`AdminAudit` 规则 C）。

## 8. 多语种与外观

语言分三层独立设置：界面语言、内容语言（标题 / 简介 / 演员名 / 标签）、音视频语言（字幕 / 音轨）。外观支持跟随系统 / 深色 / 浅色。详见 `I18n`。

- **首发语言**：简体中文、繁體中文、English、日本語、한국어、Tiếng Việt、Español、ไทย（待确认，见待决问题）。
- **URL**：带语言前缀（`/en/video/123`）+ hreflang。
- **回退**：缺翻译时按 zh-TW → zh-CN → en → 原文显示，不留空白。
- **翻译流程**：内容先机翻，再人工审核；后台每个字段每种语言显示「原文 / 已审核 / 机翻待审 / 缺失」（`AdminVideo` 多语言标签）。
- **本地化格式**：日期、数字、播放量单位（万 / K）、时长用 Intl API。
- **外观**：颜色全部用变量，深浅两套取值；浅色下强调色加深为 #9A5B00 保证对比度；播放器、全屏、横屏固定深色。示例见 `NavHomeLight` `VideoLight` `MobileHomeLight`。

## 9. 移动端

手机是主要场景，所有核心路径先按手机验收，再适配桌面。

- **底部 4 个 Tab**：首页 / 发现 / 关注 / 我的（`MobileHome` `MobileDiscover` `MobileFollowing` `MobileLibrary`）；「发现」内含热门、新上线、分类、演员四个子标签。
- **迷你播放器**：离开播放页继续播放，悬在 Tab 上方，可暂停、关闭、上滑展开。
- **底部面板优先**：片源 / 字幕 / 音轨 / 倍速、演员详情都用底部弹出的面板，不跳页（`MobileSources` `MobileActorSheet`）。
- **尺寸规则**：可点区域 ≥ 44px；正文最小 12px；底部 Tab 预留 iPhone 底部横条空间（safe-area-inset-bottom）。
- **横屏全屏**：手势见 5.1（`MobilePlayerFull`）。
- **网络**：流量下默认 720p，可在设置里改；断网时已缓冲部分继续播放（`States` 05）。

## 10. 推荐系统

推荐用「多路召回 + 统一排序」：视频、演员、用户都有向量，同一套向量同时服务首页、相关视频、相似演员三个位置。

| 召回路 | 依据 | 用在哪里 |
| --- | --- | --- |
| 行为协同 | 看过 A 的人也看了 B（播放、完播、收藏） | 首页「为你推荐」、播放页相关 |
| 演员 | 同演员、共演关系、关注的演员新作 | 播放页「同演员」、首页「关注的演员有新作」 |
| 内容 / 元数据 | 类型、标签、系列、导演、年代 | 冷启动、播放页「同系列」 |
| 向量 | 视频 / 演员 / 用户 embedding 近邻 | 相似演员、演员库「为你推荐」 |
| 热门兜底 | 热门榜、新上线 | 未登录首页、召回不足时补位 |

- **排序信号**：预估点击 × 预估观看时长，叠加多样性（同一演员连续不超过 2 个）和语言加权（有用户语言字幕或配音的优先）。
- **可解释**：每条推荐带一句理由（「同演员 · 林遥」「看过此视频的人也看了」）。
- **更新频率**：向量与热度每晚 04:30 重算（`AdminAudit` 规则 G），实时信号（刚看完的视频）在请求时叠加。
- **冷启动**：新用户首次进入选类型和演员（新手引导，待设计）；新视频先进热门兜底池和「新上线」。

### 14.2 播放事件（完整序列）

一次播放的事件顺序：`play_request` → `first_frame` → （`heartbeat` × N，中间穿插 `pause` / `seek` / `rebuffer` / `source_switch` 等）→ `play_end`。上表已有的事件保留，补充如下：

| 事件 | 关键字段 | 用途 |
| --- | --- | --- |
| `heartbeat` | 每 10 秒一次；当前位置、倍速、清晰度、是否全屏、是否画中画、页面是否在前台 | 真实观看时长；后台不计或单独计 |
| `seek` | 从哪里到哪里、方式（拖动 / 双击快进 / 章节 / 波峰 / 键盘） | 播放波峰、跳过区间 |
| `pause` / `resume` | 位置、暂停时长 | 暂停广告触发、章节截屏选取 |
| `quality_change` / `rate_change` | 前后值、手动 / 自动 | 码率策略、倍速偏好 |
| `play_end` | 结束原因（看完 / 关闭 / 连播下一个 / 出错）、累计观看秒数、本次观看区间（见 14.3） | 完播率、播放波峰 |
| `peak_click` | 曲线类型（弹幕 / 播放）、点击位置、是否点的是前 3 高峰标记、跳转后是否看满 30 秒 | 波峰是否有用 |
| `autoplay_next` | 上一个、下一个、是否取消、倒计时剩余秒数 | 连播效果 |

### 14.3 播放波峰（「最多重看」曲线）

弹幕波峰（5.5.1）反映「大家在哪里说话」，播放波峰反映「大家在哪里倒回去重看」。弹幕少的视频（小语种、老片）也能有波峰。

**客户端采集**

1. 和弹幕一样，把视频切成 200 个桶（按作品时间轴，切换片源不影响；「其他版本」单独算）。
2. 播放器在内存里为本次播放记一个 200 格的计数表：每个桶实际播放满 50% 就加 1。只算正常播放：倍速 ≤ 2×、页面在前台或画中画、不在广告中。
3. 随 `play_end` 上报这张表（压缩后小于 100 字节）；长视频每 5 分钟随 `heartbeat` 先报一次增量，防止应用被杀时丢失。

**服务端聚合**

| 指标 | 算法 | 用在哪 |
| --- | --- | --- |
| 观看人数 `viewers[b]` | 该桶计数 ≥ 1 的播放数 | 留存曲线（后台） |
| 重看人数 `replays[b]` | 该桶计数 ≥ 2 的播放数 | 播放波峰（前台） |
| 跳过人数 `skips[b]` | `seek` 向前跨过该桶且没回来看的播放数 | 跳过区间（后台） |

1. 波峰值 = `replays[b] ÷ viewers[b]`（重看率），不用绝对人数，避免开头因为人多永远最高。
2. 去掉开头 3% 和结尾 5%（片头片尾的重看多是误操作）；相邻 3 桶平滑；归一化为 0–255。
3. 防刷：同一用户或设备对同一视频，每天最多计 3 次播放；没有任何交互、连续播放超过 2 小时的设备不计。
4. 有效播放少于 1000 次时不显示曲线。每小时重算一次，结果与弹幕波峰一样存成 200 个整数的静态文件，随播放配置下发。

**前台只显示一条曲线**

- 弹幕开启且有弹幕波峰时：显示弹幕波峰（弹幕密度 70% + 重看率 30%）。
- 弹幕关闭或弹幕太少时：显示播放波峰，最高处悬停提示「最多重看」。
- 两者都没有时不显示；设置里「显示高能波峰」一个开关管两条曲线。

**后台与其他用途**

- `AdminVideo` 增加「数据」标签：留存曲线（`viewers[b]` ÷ 播放数）、重看曲线、跳过区间，章节线叠在上面。
- 中插广告：避开重看率前 3 高峰前后 60 秒；在候选章节分界里，优先选留存下降最小的位置。
- 章节缩略图、推荐卡片的预览片段，优先取重看高峰的画面。
- 跳过区间大且集中在开头时，提示运营标注片头，前台显示「跳过片头」。

### 14.5 采集与数据质量

- 上报：客户端批量发送（每 20 条或 30 秒一批），弱网时存本地队列，恢复后补发；页面关闭时用浏览器的「离开时发送」接口保证 `play_end` 能发出。
- 隐私：未同意「分析」时只发不含 `user_id` / `device_id` 的匿名计数（仍可用于波峰和片源健康）；收到 GPC 信号按未同意处理。
- 保留期：原始事件 90 天；聚合结果（曲线、日报）长期保留；用户注销账号后 30 天内删除关联。
- 校验：每个事件有字段定义，不合格的进「隔离区」不入仓；后台每天看各事件量、丢失率、`play_request` 与 `play_end` 的配对率（低于 95% 报警）。
- 上线前用测试设备走一遍完整播放流程，对照事件序列验收。

## 16. 广告

原则：广告量跟着观看意愿走，看得越久，单位时间广告越少。正片里广告每小时不超过 2 分钟；同一用户每小时广告不超过 90 秒。画板：`AdPlacements`（广告位与规则）、`AdDepth`（展示策略）、`MobileAds`、`AdminAds`。

### 16.1 广告位

| 广告位 | 规则 |
| --- | --- |
| 贴片 | 正片前，≤ 30 秒，5 秒后可跳过 |
| 中插 | 只在 20 分钟以上的视频；只落在章节分界；相隔 ≥ 15 分钟；提前 5 秒倒计时；避开波峰最高 3 处前后 60 秒 |
| 暂停 | 暂停 ≥ 2 秒后出现，继续播放即消失；横屏全屏不放 |
| 伴随 | 桌面视频页右侧 300×250 |
| 信息流 | 首页原生卡片，最多每两行一个，标「广告」 |
| 搜索推广 | 最多 1 条，必须与搜索词相关 |

不放广告的地方：演员页、登录注册、设置、法律页、后台。

### 16.2 按视频时长编排

| 时长 | 编排 |
| --- | --- |
| < 5 分钟 | 不放贴片，只有信息流和暂停广告 |
| 5–20 分钟 | 1 个贴片，≤ 15 秒 |
| 20–60 分钟 | 1 个贴片 + 最多 2 个中插 |
| > 60 分钟 | 1 个贴片 + 每 20–25 分钟 1 个中插，最多 4 个，每个 ≤ 30 秒 |

### 16.3 按用户状态调整

- 新用户：注册首日或前 3 次播放不放贴片和中插。未登录访客：首次访问前 2 个视频不放贴片。
- 连续观看：自动连播 30 分钟内，下一集只放 1 个 ≤ 6 秒的短贴片。
- 重度用户：当天观看超过 2 小时后，贴片 ≤ 15 秒，中插减半。
- 回看：24 小时内重看同一视频不放贴片；拖回已播过的中插点不重复放。

### 16.4 激励广告

用户点「4K」片源或进入中插倒计时时，可以选「看 30 秒广告，这一集解锁 4K」或「跳过本集中插」。不主动弹出；每天最多 3 次；看完才生效。以后做会员时换成「开通会员」入口。

### 16.5 边界情况

| 情况 | 处理 |
| --- | --- |
| 切换片源 | 不重新放贴片；已放过的中插点在新片源里同样跳过 |
| 拖动越过中插点 | 落点后补放最近的一个，同一点不重复 |
| 广告加载超过 2 秒 / 出错 | 直接播正片，不重试 |
| 画中画 / 后台 | 不插中插；广告计时暂停 |
| 弱网 / 省流量 | 广告用低码率；省流量模式中插减半 |
| 弹幕 | 广告期间隐藏，不能发 |
| 广告拦截器 | 正片照常播放，只提示一次「广告让 REEL 保持免费」 |

### 16.6 品牌安全与技术

- 敏感题材视频由编辑标记，只放白名单广告或不放。主演正在代言的品牌，其竞品不投在该演员的视频上。
- 广告与正片之间留 0.5 秒黑场；中插结束后从停下的位置往回 2 秒继续。
- 格式用 VAST / VMAP；贴片由客户端插入（便于计频和跳过），中插由服务端拼进视频流。
- 画面至少一半可见、连续 2 秒才计 1 次展示；埋点见 14.4。
- 实验护栏：调广告量时，人均时长、完播率、次日留存任一下降超过 2% 自动停止。

## 17. 新作提醒 · `NewWorkAlert` / `MobileNewWork`

- 入口：演员页「关注」旁的铃铛；关注后自动开启。三档：所有新作 / 只提醒主演作品 / 不提醒。
- 渠道：站内、推送、邮件，默认站内 + 推送；在「设置 › 通知」统一管理。
- 预约：演员页「即将上线」每部作品可预约，上线前一天和上线时各提醒一次；预约不需要关注演员。
- 防打扰：同一渠道每天最多 1 条，多条合并；同一部作品只提醒一次；免打扰时段（默认 22:00–8:00）的推送顺延。
- 数据来源：`AdminActors` 的「即将上线」；日期未定时只在演员页显示，不推送。

## 18. 今晚看什么 · `Tonight` / `MobileTonight`

- 入口：桌面首页横幅下方按钮、快捷键 T；手机「发现」顶部。
- 筛选：时长（不限 / 30 分钟内 / 1 小时左右 / 2 小时以上 / 剧集）、想要的感觉、和谁看。
- 一次只给一个，带一句推荐理由和自动静音的预告；操作：就看这个 / 换一个 / 稍后看 / 看过了。手机左滑换一个。
- 候选来自推荐系统，只取未看过、评分 ≥ 7.5、有可播片源的；「换一个」会降低同类型权重；「看过了」写入观看记录。
- 保留最近 3 个换掉的，可以点回去。

## 19. 评分与短评 · `Ratings` / `MobileRatings`

- 位置：视频页标题、片源和简介之下，评论之上；手机是一行摘要，点开是半屏评分面板。
- 1–5 星；视频分 = 贝叶斯平均（人少时向全站均值收缩），换算为 10 分制；少于 50 人不显示分数。剧集每集单独评分。
- 所有人都可以评分：不要求先观看，也不要求登录（未登录按设备记一票）；写短评需要登录。短评旁标注作者的观看进度（看完 / 看到 60% / 未观看）。防刷靠权重：未登录、注册不满 7 天和异常账号的票权重降低。评分对别人匿名，短评显示昵称。
- 短评最多 140 字，可标「含剧透」，默认折叠。排序：最有用（点赞 × 时间衰减）/ 最新 / 只看看完的。
- 点赞：每人每条一次，可取消；作者收到的赞每天汇总通知（可关）。
- 审核：与弹幕同一套自动审核；未标但被判为剧透的自动折叠；刷分由审核员确认后剔除。

## 20. 新手引导、设置与访客

- 新手引导 `Onboarding` / `MobileOnboarding`：注册后出现一次，3 步（语言与外观 → 选 3 个以上类型 → 关注演员）；手机把语言步骤换成「允许新作推送」。每步可跳过。
- 设置 `Settings` / `MobileSettings`：账号、播放、语言与外观、通知、隐私与数据、广告偏好。播放设置跨设备同步。
- 观看统计 `WatchStats`：只有本人可见；观看时长、看完的视频、常看演员和类型、观看时段；清除观看记录会一起清掉。
- 访客首页 `NavHomeVisitor` / `MobileHomeVisitor`：不登录也能看全部视频；用「本周热门 / 新上线 / 高分短片」代替「继续观看」和个性化行；侧栏「关注的演员」换成登录卡片。
- 合规页面 `CookieBanner` / `MobileConsent` / `AgeGate` / `CopyrightForm` / `LegalPage` 的规则见第 15 节和法律文本草稿。
- 技术方案画板：`TechRec`（推荐系统）、`TechPlayback`（播放、多片源与转码）。
